# MyVoteHub

Event voting management: companies onboard, run awards, pageants, reality shows and polls with paid (MoMo/card) or free voting, secret judges, weighted results, evictions, wallets and withdrawals.

Phase 1 is a browser-only prototype: data lives in the browser (localStorage) and payments are simulated. Demo accounts use the password `demo123`.

```bash
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages (`.github/workflows/deploy.yml`).
